Question:
Describe how the && (AND) and || (OR) operators use short-circuit evaluation. How can this be used to provide default values for variables?
The && and || operators use short-circuit evaluation, which means JavaScript stops evaluating an expression as soon as it knows the final result.

The && operator means AND. Both conditions must be truthy for the entire expression to be truthy.
You can use the || operator to provide a default value when a variable is falsy.
const name = "";
const username = name || "Guest";

console.log(username); Since name is an empty string (""), which is falsy, JavaScript uses "Guest" as the default value.

4. Nested Logic Transformation

A nested if...else can be rewritten using a ternary operator when there are only a few simple conditions.

Using if...else:

const age = 20;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

Using a ternary operator:

const age = 20;

const result = age >= 18 ? "Adult" : "Minor";
console.log(result);

The ternary operator is preferable when there is a simple condition with two possible outcomes. It makes short decisions more concise.

A switch statement is preferable when you need to compare one value against several possible specific values.

const day = 2;

switch (day) {
    case 1:
        console.log("Monday");
        break;
    case 2:
        console.log("Tuesday");
        break;
    case 3:
        console.log("Wednesday");
        break;
    default:
        console.log("Invalid day");
}

Part 4: Scopes and Variable Lifetime
17. Global vs. Local

The Global Object is an object that provides variables and functions that are available throughout a JavaScript program.

In a browser, the global object is called window. In Node.js, it is commonly accessed through global.

For example:

var name = "Honorine";

console.log(window.name);

A variable declared in the global scope can be accessed from different parts of the program.

Risks of polluting the global scope:

Global variables can accidentally be changed by different parts of the program.
Different variables can have the same name and cause conflicts.
It can make code harder to understand and maintain.
It can make debugging more difficult.

Therefore, it is generally better to keep variables inside functions or blocks when they are not needed globally.


Block Scope vs. Function Scope

The main difference is how var, let, and const behave inside blocks such as if and for.

var is function-scoped, meaning it is available throughout the function where it was declared. It does not respect block scope.

ES6 introduced let and const, which are block-scoped. This allows variables declared inside if statements and for loops to remain limited to those blocks, reducing accidental access and variable conflicts.


Shadowing

Variable shadowing happens when a variable inside a local scope has the same name as a variable in an outer scope, such as the global scope.
When this happens, JavaScript uses the variable from the closest/current scope first.JavaScript looks for name starting from where console.log(name) is located.JavaScript searches for a variable from the innermost scope outward. The closest matching variable is the one it uses.
