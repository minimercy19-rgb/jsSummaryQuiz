2. What are the primitive data types available in JavaScript, and how do they fundamentally differ from reference types like arrays and objects?
Primitive data types: simplest data types or lowest-level processing instruction that cannot be broken down further
Examples: Numbers, String, Boolean, Bigint, Null, and Undefined values
They are immutable(cannot be changed)
Stored as actual values

Reference Data Types: data types that store a memory address pointing to the actual data rather than holding the value directly
Examples: Arrays, Classes / Object, String, and Interfaces / function
They are mutable
Stored as memory address
